Database Tracking

To view tracked visits, run this SQL query:

SELECT 
    keyword,
    COUNT(*) as total_visits,
    MAX(visited_at) as last_visit,
    ip_address,
    user_agent
FROM seo_keyword_redirects 
GROUP BY keyword 
ORDER BY total_visits DESC;
